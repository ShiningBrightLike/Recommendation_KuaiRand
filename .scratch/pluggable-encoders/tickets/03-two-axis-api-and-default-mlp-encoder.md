## 交付内容

引入特征编码器与多任务结构两轴的组合 API：默认模型在共享输入之后先经过一层全连接编码器，再进入 MMoE；训练入口可切换编码器与多任务结构，对照脚本可用「结构+编码器」组合串；每个 run 的指标产物记录两轴名称、生效超参与参数量；README 明确标注旧基线数字基于旧默认模型。

## 验收标准

- [ ] 默认运行的产物集合与今天一致（输出命名、模型文件、训练曲线、训练日志）
- [ ] 默认编码器与两种单模型多输出结构均可端到端训练并落盘
- [ ] 对照脚本接受「结构+编码器」组合串；逻辑回归带后缀时报错
- [ ] 指标产物含两轴名称、生效超参与参数量
- [ ] README 标注旧基线数字基于旧默认模型
- [ ] 测试覆盖默认编码器的组合形状、输出范围与参数量记录
