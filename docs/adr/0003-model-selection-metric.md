# 模型选择指标：门控任务平均验证 AUC（val_auc_mean）

训练早停与最佳权重选择从加权 `val_loss` 改为“门控任务（点击、点赞）平均验证 AUC”，即 `val_auc_mean`，并保留 `--monitor` 允许切回 `val_loss` 或单任务 AUC。原因是加权总损失几乎完全由点击任务主导（best epoch 9 时点击占 87.0%，关注+评论合计仅 0.8%），用 `val_loss` 早停等于只选“点击模型”；而精排的核心目标是排序质量，AUC 更接近该目标。代价是选择指标不再直接反映概率校准与稀疏任务表现，因此报告仍逐任务展示全部 AUC，关注/评论作为参考列。
