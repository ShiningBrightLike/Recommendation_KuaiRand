# 模型分层：可插拔特征编码器 × 可插拔多任务结构

排序模型拆成两条正交的轴：**特征编码器**（对拼接后的特征向量做进一步表征变换，v1 含 MLP、DCN-v2、SENet）与**多任务结构**（决定任务间如何共享与分化并给出各任务输出，现有 MMoE、Shared-Bottom、单任务，后续扩展 PLE-CGC），两轴独立组合、各有统一契约与注册表，统一收进 `models/` 包；新增算法只需加一个模块并注册，不改训练主干。选择分层而非把 DCN、SENet、PLE 都塞进单一“encode 层”，是因为特征表征与任务间共享是两个正交的建模问题：合成一轴后既表达不了“MMoE + DCN”这类组合，也无法单独度量 PLE 相对 MMoE 的增量。

**Consequences**：默认模型由“共享 Embedding 直接进 MMoE”变成“先过一层 Dense 编码器”，因此 README 的 Baseline v1、`docs/assets/baselines_v1.*`、置换重要度与泄漏审计里的数字都对应旧默认模型，不再是可复现基线，需用新默认重跑后再发布；依赖旧模型的既有特征门控判定（ADR-0002 批量阶段）同样作废，重跑前不得作为采纳依据。
