# 09 bootstrap、不确定性与实验治理

## 三种不同的不确定性

不要把下列三种波动混成一个数字：

| 来源 | 项目中的处理方式 | 解释 |
| --- | --- | --- |
| 随机种子 | 多 seed 均值 ± 样本标准差 | 训练初始化和优化路径的波动 |
| 用户抽样 | 用户级 bootstrap 95% 区间 | 排序指标在用户群体上的抽样不确定性 |
| 时间窗口 | train/val/test 按时间隔离 | 分布随时间变化和未来泛化风险 |

多 seed 汇总只对每个 seed 的点估计计算均值和样本标准差；不把不同 seed 的 bootstrap 区间再次平均。

## 为什么 bootstrap 以用户为单位

同一个用户的多条曝光不是独立观测。若逐行重采样，会低估用户内相关造成的不确定性。当前排序评估默认：

- 以 user_id 为重采样单位；
- 默认 1,000 次；
- 报告 95% percentile 区间；
- ECE 也在每次用户重采样后重新合并分箱统计。

## 实验选择顺序

~~~text
train：拟合参数
  ↓
val：早停、候选比较、特征决策、排序比较
  ↓
锁定模型配置与特征组合
  ↓
test：对一个配置、一个 seed 做一次最终确认
~~~

test 一旦参与候选排序、调参或特征筛选，就不再是无偏的最终确认集。

## 发布一条实验结果前的最小元数据

至少写清：

- 模型轴和生效超参数；
- split 和时间窗口；
- seed 数量与具体 seed；
- 早停指标；
- 训练/评估行数；
- 指标定义与有效用户数；
- bootstrap 次数、随机种子和区间口径；
- 是否加载过 test；
- 结论的非目标和已知风险。
