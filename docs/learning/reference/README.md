## 证据层级

| 层级 | 可以支持什么结论 | 不能支持什么结论 |
| --- | --- | --- |
| 单元测试 / smoke | 代码契约、保存加载和基本链路可运行 | 性能更好 |
| 验证集多 seed | 候选配置在当前验证协议下的比较 | 对未来或线上一定更好 |
| 用户级排序报告 | 给定曝光集合内的重排差异 | 全库召回或线上收益 |
| test 最终确认 | 锁定配置在最终时间窗口的一次确认 | 重新选型或调参 |
| 泄漏审计 | 某类特征的关联与风险信号 | 已完成严格 point-in-time 修复 |

如果参考层与主线叙述发生冲突，优先检查 [CONTEXT.md](../../../CONTEXT.md)、相关 ADR 和 [实验台账](../../experiments.md)。
