# 限制与诚实边界

发布教程、实验结果或个人总结时，建议同时保留以下限制。

## 数据与任务

- 数据是公开曝光日志，不是线上全量候选池；
- 训练样本是曝光行，不代表所有可能被推荐的视频；
- 当前没有召回覆盖率、线上延迟、在线 CTR 或长期用户价值指标；
- 当前没有负采样、序列行为建模或因果效果评估。

## 特征与泄漏

- 视频统计特征存在全期聚合带来的 point-in-time 风险；
- 现有泄漏审计是对照证据，不是严格窗口重算；
- 置换重要度是预测依赖，不是因果解释；
- 高相关特征会让单列重要度被摊薄。

## 模型与评估

- 模型选择主要使用点击/点赞门控任务的 val_auc_mean；
- 关注和评论仍会报告，但不主导默认早停；
- 用户级排序指标只在曝光集合内定义；
- ECE 不应和排序指标混成一个总分；
- 多 seed 和 bootstrap 只能描述当前协议下的不确定性，不能替代外部时间验证。

## 工程与复现

- 生成的 data_processed 和 saved runs 是缓存或运行产物，不是教程源码依赖；
- 结果必须绑定模型轴、seed、split、特征版本和发布资产；
- 单模型脚本会读取 test，候选比较必须使用验证集流程；
- TensorFlow 日志中的 retracing 或 oneDNN 提示不等于性能结论。

这些限制不是项目失败的证明，而是解释结果时必须一起呈现的边界。
